What is recorded on the chain

Newest first. Each line is a transaction: what it means, then the contract function and transaction id.

    Local chain: 1 block = 1 epoch = 1 second here (30 seconds on Filecoin). luca_usdfc is a local test token with no value, standing in for USDFC (the dollar stablecoin used by Filecoin Pay).
    Real: Filecoin Pay (FilOzone/filecoin-pay @ 04ded6a), ComputeService, the containers. Stand-ins: PDP is simulated by a small contract, piece ids are content hashes. Proofs of possession are not run: the provider is assumed to be a real, honest provider that proves every period (the "PDP proof ✓" line is simulated).
